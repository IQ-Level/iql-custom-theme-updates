# IQL Custom Theme — kanał wersji

Publiczny plik z numerem ostatniej wersji wtyczki
[IQL Custom Theme for Elementor](https://github.com/IQ-Level/iql-custom-theme-elementor)
i opisem zmian.

Instalacje klientów czytają stąd **wyłącznie numer wersji i changelog** —
żadnego kodu, żadnego tokenu, żadnej instalacji jednym kliknięciem. Dlatego to
repozytorium jest publiczne i takie ma zostać.

```
https://raw.githubusercontent.com/IQ-Level/iql-custom-theme-updates/main/latest.json
```

Uwaga: `raw.githubusercontent.com` trzyma cache przez 5 minut, więc zaraz po
wydaniu adres jeszcze przez chwilę oddaje poprzedni numer.
